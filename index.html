Sobre mí

Soy estudiante de Análisis y Desarrollo de Software (ADSO) en el SENA, un programa tecnólogo enfocado en el ciclo completo del desarrollo: desde el análisis de requerimientos hasta la implementación y pruebas de software.

En el área técnica manejo Python como lenguaje principal y Django como framework backend, con el que construyo aplicaciones web, sistemas de autenticación y APIs REST. Complemento con SQL para bases de datos relacionales, Git para control de versiones y HTML/CSS para integrar vistas. Mi entorno de trabajo es PyCharm.

En equipo me desenvuelvo bien — en el proyecto Agropecuario.NET trabajé junto a compañeros coordinando tareas, usando Git para no pisarnos el código y comunicando avances constantemente. Me gusta que el equipo funcione, no solo yo.

Tengo muchas ganas de seguir creciendo. Quiero profundizar en arquitectura backend, buenas prácticas con Django REST Framework y eventualmente aprender sobre despliegue en la nube. Cada proyecto que hago me deja algo nuevo y eso es lo que me motiva.

Sistema de Programación de Instructores y Fichas

Aplicación web llamada Agropecuario.NET, desarrollada para el SENA, que automatiza la programación y asignación de instructores a fichas de formación. El sistema maneja dos roles: Dinamizador (administrador que programa y gestiona fichas) e Instructor (visualiza su calendario, controla sus horas mensuales y registra actividades). Reemplazó el proceso manual de cruce de horarios, eliminando conflictos de asignación.

Mi rol — Desarrollo backend completo Fui pieza fundamental del equipo: desarrollé todo el backend con Django, la lógica de roles y permisos, el sistema de autenticación, la gestión de programación por calendario y el control de horas por instructor.
